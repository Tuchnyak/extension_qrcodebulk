# AGENTS.md - Bulk QR Code Generator Chrome Extension

## Project Overview

This is a Chrome extension (Manifest V3) for bulk-generating QR codes from URLs or CSV data. It operates in a dedicated browser tab with a rich UI for managing input, settings, and generation.

**Chrome Web Store:** https://chromewebstore.google.com/detail/bulk-qr-code-generator/nkpcheohehognkoamimhhjpgclhhleap

**Key Dependencies:**
- `qrcode` - QR code generation
- `jszip` - ZIP archive creation
- `esbuild` - JavaScript bundling
- `copyfiles` - Copy static assets during build

**Project Structure:**
```
src/                    # Source files (development)
  background.js         # Service worker (extension icon click handler)
  bulk.html            # Main UI HTML
  bulk.css             # Styles
  bulk.js              # Main application logic
dist/                   # Built files (generated by npm run build)
icons/                  # Extension icons (16, 48, 64, 96, 128 px + source.svg)
locales/                # i18n message files
manifest.json           # Extension manifest (MV3)
```

---

## Build Commands

```bash
# Install dependencies
npm install

# Build for development (bundles JS, copies HTML/CSS to dist/)
npm run build

# Create release package and ZIP archive
npm run zip
```

**Important:** The `dist/` directory contains bundled output. Always run `npm run build` after modifying source files before testing in Chrome.

**Load Extension in Chrome:**
1. Open `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select the project root directory

## Chrome Extension Specifics

**Manifest V3 Requirements:**
- Background script is a **service worker** (no persistent background page)
- Use `chrome.downloads.download()` for file downloads
- Use `chrome.storage.local` for persistent data
- Service worker lifecycle: listen for `chrome.runtime.onInstalled`

**Service Worker Pattern (background.js):**
```javascript
chrome.action.onClicked.addListener((tab) => {
    chrome.tabs.create({ url: 'dist/bulk.html' });
});

chrome.runtime.onInstalled.addListener((details) => {
    if (details.reason === chrome.runtime.OnInstalledReason.INSTALL) {
        chrome.tabs.create({ url: 'https://...' });
    }
});
```

## Performance Considerations

- Use `nextTick()` helper (Promise + setTimeout(0)) to yield to UI during bulk operations
- Disable UI controls during generation to prevent concurrent modifications
- Update progress every N items (e.g., `if (i % 5 === 0)`) to reduce DOM updates
